# docchat

A command-line chatbot that remembers your conversation. It sends your messages to a language model through the Groq API.

## Install

    python -m pip install .

## Use

Put your key in a `.env` file (`GROQ_API_KEY=your_key`), then run:

    chat

Press Ctrl+C or Ctrl+D (Ctrl+Z then Enter in PowerShell) to exit.
